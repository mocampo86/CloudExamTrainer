# Story Ready Checklist

- [ ] El objetivo describe un resultado y no una actividad vaga.
- [ ] Los Acceptance Criteria son verificables.
- [ ] El Out of Scope está definido.
- [ ] Se conoce el proyecto o módulo afectado.
- [ ] Las dependencias están identificadas.
- [ ] No hay decisiones arquitectónicas críticas abiertas.
- [ ] Los datos de prueba requeridos están disponibles.
