# Code Review Checklist

## Funcionalidad

- [ ] Cumple la historia.
- [ ] Maneja escenarios negativos.
- [ ] No rompe flujos existentes.

## Arquitectura

- [ ] Respeta separación por capas y features.
- [ ] No agrega dependencias innecesarias.
- [ ] No acopla contenido a componentes.

## Datos

- [ ] IDs únicos.
- [ ] Contratos y schemas alineados.
- [ ] LocalStorage versionado.
- [ ] Migraciones o compatibilidad consideradas.

## UI

- [ ] Estados de carga, error y vacío.
- [ ] Navegación accesible.
- [ ] Inputs con labels.
- [ ] Soporte responsive básico.

## Pruebas

- [ ] Lógica crítica cubierta.
- [ ] Casos borde cubiertos.
- [ ] Pruebas no dependen del orden aleatorio.
