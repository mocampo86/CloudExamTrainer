# Pre-Merge Checklist

- [ ] La implementación cumple todos los Acceptance Criteria.
- [ ] No se implementó Out of Scope.
- [ ] No hay secretos, tokens ni URLs privadas.
- [ ] No hay `console.log` temporales.
- [ ] No hay `any` injustificado.
- [ ] No hay código muerto.
- [ ] Los tests pasan.
- [ ] El lint pasa.
- [ ] El build pasa.
- [ ] Los JSON pasan validación.
- [ ] La documentación fue actualizada.
- [ ] El diff fue revisado manualmente.
