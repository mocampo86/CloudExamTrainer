# Definition of Done

Una historia solo está terminada cuando:

- Todos los Acceptance Criteria están implementados.
- No se implementó funcionalidad fuera de alcance.
- El proyecto compila.
- El lint finaliza correctamente.
- Las pruebas relevantes pasan.
- Se agregaron o actualizaron pruebas cuando corresponde.
- Los JSON pasan las validaciones.
- La documentación afectada fue actualizada.
- No existen secretos ni datos sensibles.
- Se revisaron errores de consola y warnings relevantes.
- El agente entrega un resumen de archivos modificados y verificaciones ejecutadas.
