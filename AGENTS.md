# Cloud Exam Trainer AI Kit (MVP)

Objetivo: construir una SPA simple (React+TS+Vite) con preguntas JSON, cuestionarios, resultados por tema y despliegue en Azure Static Web Apps.

No implementar: backend, DB, autenticación, usuarios, API, Azure Functions, PWA.

Regla: implementar la solución más simple que cumpla los Acceptance Criteria.
