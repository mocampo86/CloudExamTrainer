# US-012 - Mostrar resultados del cuestionario

## Objetivo

Presentar al usuario un resumen claro del desempeño obtenido.

## Acceptance Criteria

- Se muestra puntaje total.
- Se muestra porcentaje.
- Se muestra lista de temas.
- Se muestran recomendaciones.
- Se puede repetir el cuestionario.
- Se puede volver al inicio.
- Existen pruebas básicas de render.

## Tasks

T001 Crear ResultsPage.
T002 Crear ResultSummary.
T003 Mostrar temas ordenados.
T004 Mostrar recomendaciones.
T005 Agregar botones de navegación.
T006 Agregar pruebas.

## Prompt IA

Implementar únicamente la pantalla de resultados usando la información generada por el scoring.
