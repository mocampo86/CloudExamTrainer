# 01.04 - Evaluación de resultados

## Objetivo

Calcular el resultado del cuestionario, evaluar el desempeño por tema y mostrar al usuario qué áreas necesitan mayor atención.

## Acceptance Criteria

- Se calcula el puntaje total.
- Se calcula el porcentaje de respuestas correctas.
- Se calcula el desempeño por tema.
- Los temas se ordenan del más débil al más fuerte.
- Se clasifican los temas según umbrales configurables.
- Se muestran recomendaciones por tema.
- Se crea una pantalla de resultados.
- El usuario puede repetir el cuestionario.
- El usuario puede volver a seleccionar un tema.
- Existen pruebas unitarias.
- El proyecto compila sin errores.

## Out of Scope

- No guardar historial.
- No sincronizar resultados.
- No IA para recomendaciones.
- No estadísticas históricas.
- No ranking de usuarios.

## User Stories

- US-010 - Calcular resultados del cuestionario.
- US-011 - Identificar temas a reforzar.
- US-012 - Mostrar resultados del cuestionario.
