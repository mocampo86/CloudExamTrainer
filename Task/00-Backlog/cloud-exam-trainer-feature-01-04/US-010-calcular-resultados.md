# US-010 - Calcular resultados del cuestionario

## Objetivo

Calcular el resultado general del cuestionario a partir de las respuestas registradas.

## Acceptance Criteria

- Se calcula cantidad correcta.
- Se calcula cantidad incorrecta.
- Se calcula porcentaje.
- Las preguntas múltiples requieren coincidencia exacta.
- El cálculo es independiente del orden de las respuestas.
- Existen pruebas unitarias.

## Tasks

T001 Crear `scoringService`.
T002 Calcular correctas.
T003 Calcular incorrectas.
T004 Calcular porcentaje.
T005 Agregar pruebas.
T006 Ejecutar lint, test y build.

## Prompt IA

Implementar únicamente la lógica de cálculo. No mostrar UI ni recomendaciones.
