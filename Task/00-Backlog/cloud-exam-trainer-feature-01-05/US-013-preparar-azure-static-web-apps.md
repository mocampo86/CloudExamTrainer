# US-013 - Preparar aplicación para Azure Static Web Apps

## Objetivo

Preparar la SPA para ejecutarse correctamente en Azure Static Web Apps.

## Acceptance Criteria

- Existe `staticwebapp.config.json`.
- Se configura `navigationFallback`.
- Las rutas SPA funcionan.
- Se documentan variables de entorno frontend.
- El proyecto compila.

## Tasks

T001 Crear `staticwebapp.config.json`.
T002 Configurar fallback a `index.html`.
T003 Verificar rutas.
T004 Documentar variables.
T005 Ejecutar build.

## Prompt IA

Preparar únicamente la aplicación para Azure Static Web Apps. No crear recursos Azure.
