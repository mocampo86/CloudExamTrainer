# US-014 - Configurar CI/CD

## Objetivo

Agregar una configuración base para despliegue automático.

## Acceptance Criteria

- Existe workflow de GitHub Actions.
- Ejecuta install.
- Ejecuta lint.
- Ejecuta tests.
- Ejecuta build.
- Publica usando Azure Static Web Apps Action.

## Tasks

T001 Crear workflow.
T002 Configurar Node LTS.
T003 Ejecutar npm ci.
T004 Ejecutar lint.
T005 Ejecutar test.
T006 Ejecutar build.
T007 Documentar secrets requeridos.

## Prompt IA

Crear únicamente el workflow y la documentación asociada.
