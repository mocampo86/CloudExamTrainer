# 01.05 - Despliegue en Azure Static Web Apps

## Objetivo

Preparar y documentar el despliegue del MVP en Azure Static Web Apps.

## Acceptance Criteria

- Se documenta la arquitectura de despliegue.
- Se configura la aplicación como SPA.
- Se agrega `staticwebapp.config.json`.
- Se documentan variables de entorno.
- Se prepara CI/CD.
- Se documenta el despliegue manual inicial.
- No existen secretos en el repositorio.

## Out of Scope

- No crear recursos Azure.
- No configurar dominio.
- No configurar HTTPS personalizado.
- No implementar backend.
- No configurar monitoreo.
- No configurar múltiples ambientes.

## User Stories

- US-013 - Preparar aplicación para Azure Static Web Apps.
- US-014 - Configurar CI/CD.
- US-015 - Documentar despliegue inicial.
